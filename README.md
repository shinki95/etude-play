# 에튀드 플레이 (트럼펫)

내 교재 에튀드를 MusicXML로 넣으면, 소리와 박자를 들려주고 마이크로 내 연주를 채점하는 연습 화면. 파일 하나(`index.html`), 서버 없음, 기록은 기기 브라우저에만 저장.

- 화면: https://shinki95.github.io/etude-play/
- 악보 파일은 이 저장소에 넣지 않는다(교재 저작권). 사장님 기기에서 "악보 파일 가져오기"로만 넣는다.

## 훈련 설계 원칙 → 기능

| 원칙 (근거) | 앱에서 |
|---|---|
| 의도적 훈련: 짧은 단위, 될 듯 말 듯한 난이도, 즉각 피드백, 난이도 조금씩 (Ericsson / 김창준 "한 단계 3분 이하") | **구간 훈련**: 가장 약한 8박 조각, 3분 블록. 90%↑ 템포 +4, 70%↓ −4 (계단식 조정). 음마다 바로 정확/좋음/늦음/다른 음 판정 |
| 같은 것도 매번 다르게 (variance) | 구간 훈련 3·4번째 판은 자동으로 "외워서", "메트로놈 없이" |
| 바람직한 어려움: 섞기·간격 (Bjork, 야생 학습 4장 105~109쪽) | **섞기**: 여러 곡의 8박 조각을 뒤섞어 한 번씩. 홈에 "오늘 n분·연속 n일", 하루 15분 순서 |
| 인출 연습 / 비계 걷어내기 | **외워서**: 음표가 판정선에 가까워지면 사라짐. 운지 숫자는 마디가 두 번 연속 90%를 넘으면 자동으로 숨김 |
| 유창성: 익숙한 재료 + 속도 압박 + 많은 양 + 멈추지 않기 (Paul Nation fluency strand, 4/3/2) | **유창성**: 깨끗하게 된 최고 템포 → +8% → +15% 세 판, 멈춤 없음. 지표 = 1분에 맞힌 음 수 |
| 귀 먼저 (McPherson: 귀로 불기가 즉흥을 예측) | **듣기**, **메아리**(앱이 8박 불면 바로 따라 불기, 채점) |
| 가설 → 관찰 → 해석 (야생 학습 2장 액관해) | 시작 전 예상 정확도 한 번 탭 → 끝나고 실제와 차이 |
| 외재적 부하 줄이기 (인지 부하 이론) | 실제 오선 위치 그대로, 운지 숫자는 음표 바로 밑, 조표는 고정 |

## 프리모템 (실패 → 대책)

1. 게임 실력만 늘고 책 보고는 못 분다 → 음높이 = 실제 오선 위치, 조표 유지, 운지·음이름은 잘 되면 사라짐. 마지막엔 책 보고 불기.
2. 마이크가 엉뚱한 음으로 판정 → YIN 음높이 + 반음 반올림(±50센트 허용), 1/2 다운샘플로 휴대폰에서도 가볍게. 셀프테스트(`?selftest=1`)로 100% 나오는지 확인.
3. 같은 음 반복(16분, 셋잇단)은 음높이로 구분이 안 된다 → 소리 세기의 골-봉우리로 혀치기 감지. 안 들리면 "혀치기 안 들림".
4. 휴대폰·블루투스 지연으로 다 늦게 판정 → 박자 보정(클릭 8번에 '투').
5. 스피커 가이드 소리를 마이크가 내 소리로 착각 → 채점 중 가이드 기본 끔(이어폰일 때만 켜기), 메아리는 듣기와 불기를 시간으로 나눔.
6. 재미있어서 몰아서 오래 한다(블록·집중 학습) → 3분 블록이 끝나면 다른 구간·섞기로 넘기기 안내.
7. 악보 인식 오류 → 교재는 사람이 원본과 대조해 MusicXML로 만들고, 화면이 실제 오선으로 보여줘 틀린 음이 눈에 띔.

## 시험 훅
- `?selftest=1`: 마이크 대신 앱 신스 소리를 분석기에 넣는다. `&shift=2`(틀린 음), `&late=150`(ms 늦게), `&drop=0.3`(빠뜨리기).
- 2026-11-17 결과: Etude 1·2 전체 100%, shift 2 → 다른 음 12/12, late 150 → 박자 어긋남 12/12(평균 146ms), late 70 → 좋음 12/12, 보정 120ms 주입 → 118ms.
