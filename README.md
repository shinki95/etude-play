# 에튀드 플레이 (트럼펫)

내 교재 에튀드를 MusicXML(또는 교재 묶음 .json)로 넣으면, 실제 악보 모양으로 보여 주고, 읽기 → 듣기 → 불기 순서로 연습시키고, 마이크로 채점하는 화면. `index.html` + `vendor/osmd.min.js`(OpenSheetMusicDisplay, BSD), 서버 없음. 기록은 localStorage, 악보는 IndexedDB(기기 안).

- 화면: https://shinki95.github.io/etude-play/
- 악보 파일은 이 저장소에 넣지 않는다(교재 저작권). 사장님 기기에서 "악보 파일 가져오기"로만 넣는다.

## 훈련 설계 원칙 → 기능

| 원칙 (근거) | 앱에서 |
|---|---|
| 의도적 훈련: 짧은 단위, 될 듯 말 듯한 난이도, 즉각 피드백, 난이도 조금씩 (Ericsson / 김창준 "한 단계 3분 이하") | **구간 훈련**: 가장 약한 8박 조각, 3분 블록. 90%↑ 템포 +4, 70%↓ −4 (계단식 조정). 음마다 바로 정확/좋음/늦음/다른 음 판정 |
| 같은 것도 매번 다르게 (variance) | 구간 훈련 3·4번째 판은 자동으로 "외워서", "메트로놈 없이" |
| 바람직한 어려움: 섞기·간격 (Bjork, 야생 학습 4장 105~109쪽) | **섞기**: 여러 곡의 8박 조각을 뒤섞어 한 번씩. 홈에 "오늘 n분·연속 n일", 하루 15분 순서 |
| 인출 연습 / 비계 걷어내기 | **외워서**: 음표가 판정선에 가까워지면 사라짐. 운지 숫자는 마디가 두 번 연속 90%를 넘으면 자동으로 숨김 |
| 유창성: 익숙한 재료 + 속도 압박 + 많은 양 + 멈추지 않기 (Paul Nation fluency strand, 4/3/2) | **유창성**: 깨끗하게 된 최고 템포 → +8% → +15% 세 판, 멈춤 없음. 지표 = 1분에 맞힌 음 수 |
| 듣기 전에 스스로 떠올리기: 생성 효과·사전 시험, 예측 오류가 학습을 이끈다 (야생 학습 2장 가설 → 액관해, 사장님 2026-11-18 "악보 보고 먼저 시뮬레이션 → 듣고 → 맞춰 연습") | **읽고·듣고·불기**(기본 모드): ① 소리 없이 파란 음표를 따라 밸브를 누르며 속으로 불기, 막힌 마디 표시 ② 듣고 예측과 비교(다르게 들린 마디 표시) ③ 불어서 채점 → "읽을 때 막힌 마디 vs 실제 약한 마디"(맞힌 예측·몰랐던 약점·괜한 걱정) |
| 실제 악보로 읽기 (전이: 책을 보고 불 수 있어야 함) | 기본 보기 = 오선 악보(OSMD, 빔·조표·셋잇단 그대로), 지금 음 파랑, 판정 초록/노랑/빨강. 흐름 보기는 선택 |
| 가설 → 관찰 → 해석 (야생 학습 2장 액관해) | 시작 전 예상 정확도 한 번 탭 → 끝나고 실제와 차이 |
| 외재적 부하 줄이기 (인지 부하 이론) | 실제 오선 위치 그대로, 운지 숫자는 음표 바로 밑, 조표는 고정 |

## 2026-11-20 미니멀 정리
- 위: 단계 연습 · 음 맞추기 · 끝까지 + 더보기(구간 훈련·유창성·섞기·듣기만) + 설정(보기·운지·외워서·메트로놈·가이드·음높이 줄·글자 크기·박자 보정).
- 아래 고정 바: 구간(마디 탭)·반복 / 템포 −+ / ↺ 다시(하는 중이면 처음부터) / ▶ 시작·■ 멈춤 한 버튼. 키보드: 스페이스 시작·멈춤, R 다시.
- 결과 카드는 악보 위: 큰 점수 + [다시][틀린 마디만][느리게 −4][빠르게 +4], 나머지는 '자세히'.

## 2026-11-21 핵심만 (사장님): 듣고 불기 · 바로 불기 · 테스트
- 듣고 불기: 고른 마디를 듣고 → [불기 / 다시 듣기] → 채점. 반복을 켜면 듣기·불기를 계속 번갈아.
- 바로 불기: 채점만. 반복·템포 자동과 조합.
- 테스트: 곡 전체 한 번, 가이드 없이, 기록(날짜·%·템포) 남기고 지난번과 비교.
- 읽기 단계·음 맞추기·구간 훈련·유창성·섞기 모드는 화면에서 뺌(코드는 남아 있음, git 이전 커밋으로 되살릴 수 있음). 실시간 음높이 색(빨강/파랑/초록)과 음높이 줄은 모든 모드에 그대로.

## 프리모템 (실패 → 대책)

1. 게임 실력만 늘고 책 보고는 못 분다 → 기본 보기를 실제 악보로, 듣기 전에 읽기 단계. 운지는 잘 되면 사라짐.
1-1. 순서는 사용자가 고른다(2026-11-18): 읽기→듣기→불기(추천) / 듣기→읽기→불기 / 읽기→불기(초견) / 듣기→불기 / 바로 불기. 읽기가 들어간 순서만 '내 예측 vs 실제'를 보여 줌.
1-2. 따라 하기만 하면 실력이 안 는다(사장님 지적) → 듣기보다 읽기가 먼저인 읽고·듣고·불기를 기본으로, 듣기만 모드는 맨 뒤로.
2. 마이크가 엉뚱한 음으로 판정 → YIN 음높이 + 반음 반올림(±50센트 허용), 1/2 다운샘플로 휴대폰에서도 가볍게. 셀프테스트(`?selftest=1`)로 100% 나오는지 확인.
3. 같은 음 반복(16분, 셋잇단)은 음높이로 구분이 안 된다 → 소리 세기의 골-봉우리로 혀치기 감지. 안 들리면 "혀치기 안 들림".
4. 휴대폰·블루투스 지연으로 다 늦게 판정 → 박자 보정(클릭 8번에 '투').
5. 스피커 가이드 소리를 마이크가 내 소리로 착각 → 채점 중 가이드 기본 끔(이어폰일 때만 켜기), 메아리는 듣기와 불기를 시간으로 나눔.
6. 재미있어서 몰아서 오래 한다(블록·집중 학습) → 3분 블록이 끝나면 다른 구간·섞기로 넘기기 안내.
7. 악보 인식 오류 → 교재는 사람이 원본과 대조해 MusicXML로 만들고, 화면이 실제 오선으로 보여줘 틀린 음이 눈에 띔.

## 시험 훅
